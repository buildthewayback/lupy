| D-004 | Persistence = **append-only JSON-lines event journal + periodic JSON snapshot** in `~/Library/Application Support/Lupy/` (human-readable), with per-line checksum, SHA-256 hash chain, torn-tail recovery, idempotent event IDs, schema versioning + migration hook. | Satisfies audit trail, crash safety, idempotency, portability and readability with zero dependencies, fully testable in the sandbox. Data volume for one founder (thousands of tasks) fits in memory. Revisit if search/scale needs grow. | ACTIVE | Moderate (export/import format is stable JSON) |

| D-015 | App target compiles in **Swift 5 language mode with minimal concurrency checking**; LupyCore itself is verified under Swift 6 strict concurrency in the sandbox (and natively on the runner). | The app shell can only be compiled on scarce macOS runners; strict-concurrency diagnostics in AppKit/Speech/URLSession glue are the most likely source of first-build failures. | D-017 | Execution strategy: **API-first, native macOS automation as the only fallback**; Safari WebDriver only on demand later; no Playwright, no visual computer control in v1. | D-018 | Delivery = **one single-file artifact behind a direct link**: `upload-artifact@v7` with `archive: false` uploads `Lupy-<ver>-<sha10>-macOS-arm64.zip` (only Lupy.app inside, made with `ditto --keepParent`), retained 90 days. Every build then **downloads that exact file on fresh `macos-14` and `macos-latest` machines** and checks it like a person would (contents, signature, install, launch, quit, relaunch, self-test, Gatekeeper preview) before it is reported. The Coucou MIT notice is bundled inside the app (`Contents/Resources/THIRD_PARTY_NOTICES.txt`). No GitHub Release. | The founder's ZIP was the repository's source code (Code → Download ZIP), and the old artifact was a zip inside a zip. A Release would publish (needs approval; upload host unreachable from the sandbox); uploading the `.app` folder strips executable bits and symlinks. Cost ≈ 7–9 macOS minutes per build. | ACTIVE | Easy |
