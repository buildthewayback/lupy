## Spec (BLUEPRINT section 6A)
- Model-agnostic skill packages in the Claude-SKILL.md style (instructions + optional
  scripts/resources) — the SAME skill works with any connected model; a skill is data the
  orchestrator feeds its workers, not a Claude-only feature.
- Progressive disclosure: skill metadata always in context; full body loads only when a
  task matches. Hundreds of skills stay cheap.
- Sources: (1) bundled default library, target ~100 at launch, quality-first; (2) internet
  registries / GitHub / URLs via Settings > Skills; (3) SELF-INSTALL: Lupy researches his
  own gaps, finds skills, vets, installs (approval only for consequential/dangerous ones).
- Vetting + trust: scan for prompt-injection / dangerous instructions / exfiltration;
  trust levels; provenance; per-skill enable/disable; versioned updates; uninstall.
  Skills are instructions — treat as untrusted code.
- Compounding loop: discover → vet → install → use → measure → upgrade/prune. Learned
  recipes export as CUSTOM SKILLS — Lupy crafts his own over time.
- MCP client support (agent-added): the Model Context Protocol tool-server ecosystem as
  another source of hands.
- Founder cost stance: data use is fine if Lupy is smart; progressive disclosure + budget
  caps keep the ceiling.
