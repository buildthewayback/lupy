# LUPY 3 — install in three clicks

**Download the kit (~32 MB):**
[Lupy-3-Install-Kit.zip — official GitHub archive of this release](https://github.com/buildthewayback/lupy/archive/refs/tags/lupy3-final.zip)
(click → it downloads a zip; that IS the kit).

1. Double-click the zip → a folder opens.
2. Double-click **Install LUPY** — the app with his own face (the white Lupy glowing on dark).
   If macOS says it cannot verify it: **right-click it → Open → Open.** (Once, ever.)
3. Plain macOS windows walk you from there — **no Terminal ever opens**. The first
   install builds for a few minutes (it fetches one small library and compiles LUPY
   with Apple's free tools; if those are missing, the installer offers Apple's own
   small download and carries on by itself). At the end LUPY launches by himself
   and lives in **Applications** from now on — his own icon, his own name, like any app.

He is the small dark pill at the top centre of your screen, under the menu bar.
Menu bar → **Lupy → Demo mode** shows his approval card; click his typing box to talk.

**What's new in this kit:** LUPY finally wears his own face — the app icon is forged
from his locked character (pure-white body, tall black capsule eyes, white glow on
dark), the same geometry the app itself draws, byte-checked by the build. The
installer is now a real double-click app with native progress windows instead of a
Terminal script; **Install LUPY.command** stays in the kit as the Terminal backup.

Needs macOS 15+ and Apple Silicon. No Xcode, no Terminal typing, no pastes.
If the installer ever can't finish, it tells you why in plain words and offers the
install log — screenshot it and send it; a new kit arrives.

Fine print, honest: the kit builds LUPY on your Mac with Apple's free Command Line
Tools and signs him ad-hoc (a paid Apple developer account would add notarization;
not yet). GitHub's cloud Macs stopped provisioning for this account, which is why
the product arrives as a self-building kit instead of a pre-built dmg.
