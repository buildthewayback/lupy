LUPY 3 — INSTALL (three clicks, no Terminal typing)

1. Double-click the downloaded zip → a folder opens.
2. Double-click "Install LUPY.command".
   If macOS says it cannot verify it: RIGHT-click it → Open → Open. (Once, ever.)
3. A window opens and builds for a few minutes (first time only — it downloads one
   small library and compiles LUPY with Apple's free tools already on your Mac).
   At the end LUPY launches by himself and lives in Applications from now on.

He is the small dark pill at the top centre of your screen, under the menu bar.
Menu bar → Lupy → Demo mode shows his approval card; click his box to talk to him.

Needs: macOS 15 or newer, Apple Silicon. No Xcode. No pastes. No Terminal typing.
If the window ever says INSTALL FAILED: screenshot it, send it, new kit arrives.
